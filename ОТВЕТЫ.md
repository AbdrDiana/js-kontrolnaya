## Часть A. Почему так

### A1 — почему изменилось и у `a`

Переменные a и b указывают на один и тот же объект
Когда мы меняем значение n через b, оно автматически меняется и при обращении через a

### A2 — почему `3` раньше `2`

Promise.then() выполняется раньше потому что попадают в очередь микрозадач
setTimeout() в очередь обычных задач
Сначала JavaScript выполняет основной код, потом микрозадачи и только после них таймеры

### A3 — почему счётчик остался нулём

Стрелочная функция работает с this и не привязывается к объекту counter
При вызове add() изменяется не свойство n самого объекта
Здесь лучше использовать обычную функцию

### Ошибка 2

**Было не так:** сортировка по важности не работала, так как в task.sort() не было параметров. Раньше sort() сортировал задачи как обычные строки

**Исправил:** tasks.sort((f,s) => s.priority - f.priority); теперь sort() сравнивает свойство priority и ставит задачи с большей важностью (10, 9, 3, 2) выше

### Ошибка 3

**Было не так:** не работала кнопка для только важных событий, было tasks.filter((task) => task.priority >= 5); filter() создаёт новый массив

**Исправил:** tasks = tasks.filter((task) => task.priority >= 5); теперь в tasks сохраняются только задачи с важностью от 5 и выше после чего список обновляется

### Ошибка 4

**Было не так:** удаление работало не исправно; проблема в типе id, в массиве id хранится числом и из-за строгого сравнения === задача не находится; из-за indexOf(undefined) получался индекс -1, и splice(-1, 1) удалял последнюю задачу вместо нужной

**Исправил:** преобразовала id в число и нахожу индекс задачи напрямую

function removeTask(id) {
  const index = tasks.findIndex((task) => task.id === Number(id));

  if (index === -1) return;

  tasks.splice(index, 1);
  render();
}
